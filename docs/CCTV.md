# ใช้กล้องวงจรปิด (CCTV) กับ PlateScan

## ทำไมใส่ลิงก์กล้องในเว็บ Vercel ตรงๆ ไม่ได้

เว็บ Vercel เป็น `https://` ส่วนกล้องวงจรปิดอยู่ในวงแลน เช่น `169.254.113.15` หรือ `192.168.1.64` การเปิดกล้องจากเว็บนี้ตรงๆ จึงติดหลายเรื่อง:

- **ลิงก์ `http://` ของกล้อง:** เบราว์เซอร์บล็อก เพราะหน้าเว็บเป็น https (mixed content)
- **ลิงก์ `https://` ของกล้อง:** ถึงจะเปิด HTTPS ในหน้าตั้งค่ากล้องแล้วก็ยังใช้ไม่ได้ เพราะ
  - ใบรับรองของกล้องเป็นแบบ self-signed เบราว์เซอร์จึงไม่เชื่อถือ
  - กล้องไม่ส่ง CORS หน้าเว็บจึงเห็นภาพได้ แต่ดึงพิกเซลมาอ่านป้ายไม่ได้ (canvas tainted)
  - กล้อง Hikvision ใช้รหัสแบบ Digest ซึ่งเบราว์เซอร์ไม่ส่งให้รูปจากเว็บอื่น
- **`rtsp://`:** เบราว์เซอร์ไม่รองรับเลย
- **ให้ Vercel ไปดึงภาพให้:** ไม่ได้ เพราะเซิร์ฟเวอร์ Vercel อยู่บนอินเทอร์เน็ต เข้าไม่ถึงวงแลนของวิทยาลัย

ทางที่ใช้ได้จริงคือรัน **ตัวกลาง** (`tools/cctv-relay.js`) บนคอมที่ต่อกับกล้องได้ เช่นคอมที่เปิดหน้าตั้งค่ากล้องได้อยู่แล้ว ตัวกลางจะทำ 3 อย่าง:

1. เปิดหน้า PlateScan ให้ที่ `http://localhost:8080`
2. ดึงภาพจากกล้องให้ (รองรับรหัสกล้องและ https ของกล้อง)
3. ส่งผลอ่านป้ายต่อไปที่เว็บ Vercel จริง ข้อมูลจึงยังลง Google Sheet และแจ้ง LINE เหมือนเดิม

## ติดตั้ง (ครั้งเดียว)

1. ติดตั้ง **Node.js LTS** จาก https://nodejs.org (กด Next ไปจนจบ)
2. ดาวน์โหลดโปรเจกต์นี้จาก GitHub: ปุ่ม Code แล้วเลือก Download ZIP จากนั้นแตกไฟล์
3. (เฉพาะถ้าจะใช้ลิงก์ `rtsp://`) ติดตั้ง ffmpeg: เปิด PowerShell แล้วพิมพ์ `winget install ffmpeg` จากนั้นปิดแล้วเปิดหน้าต่างใหม่

## ใช้งาน

1. ดับเบิลคลิก `tools/start-cctv-relay.bat` หรือเปิด Command Prompt ในโฟลเดอร์โปรเจกต์แล้วพิมพ์

   ```
   node tools/cctv-relay.js
   ```

2. เปิดเบราว์เซอร์ไปที่ **http://localhost:8080** (ต้องเป็นลิงก์นี้ ไม่ใช่เว็บ Vercel)
3. กด **ลิงก์สตรีม** แล้วใส่ลิงก์กล้อง ใส่ชื่อผู้ใช้และรหัสไว้ในลิงก์ได้เลย
4. โหมด "อ่านเรียลไทม์" จะเปิดเอง ระบบตีกรอบป้าย อ่าน และบันทึกให้

ต้องเปิดหน้าต่างตัวกลางทิ้งไว้ตลอดที่ใช้งาน ถ้าปิดหน้าต่าง หน้าเว็บที่ localhost จะดึงภาพกล้องไม่ได้

## ลิงก์กล้อง Hikvision

แทน `admin`, `รหัส` และ IP ด้วยของกล้องจริง ตัวอย่างนี้ใช้ IP ในหน้าตั้งค่า `169.254.113.15`

| แบบ | ลิงก์ | หมายเหตุ |
| --- | --- | --- |
| ภาพนิ่ง (แนะนำ เริ่มจากอันนี้) | `http://admin:รหัส@169.254.113.15/ISAPI/Streaming/channels/101/picture` | ตัวกลางขอภาพใหม่ประมาณ 4 ครั้งต่อวินาที ไม่ต้องลง ffmpeg |
| ภาพนิ่งผ่าน https | `https://admin:รหัส@169.254.113.15/ISAPI/Streaming/channels/101/picture` | ใช้ได้เหมือนกัน ตัวกลางยอมรับใบรับรอง self-signed ของกล้อง |
| วิดีโอ RTSP (ลื่นกว่า) | `rtsp://admin:รหัส@169.254.113.15:554/Streaming/Channels/101` | ต้องลง ffmpeg; ใช้ `102` แทน `101` ถ้าอยากได้สตรีมรองที่เบากว่า |

ถ้ารหัสมีอักขระพิเศษ เช่น `@ # : /` ให้เปลี่ยนเป็นรหัสที่มีแต่ตัวอักษรกับตัวเลข หรือเข้ารหัสแบบ URL ก่อน เช่น `@` เป็น `%40`

ยี่ห้ออื่น เช่น Dahua ภาพนิ่งอยู่ที่ `http://admin:รหัส@IP/cgi-bin/snapshot.cgi` และ RTSP อยู่ที่ `rtsp://admin:รหัส@IP:554/cam/realmonitor?channel=1&subtype=0`

## ตัวเลือกเพิ่มเติม

- `--lan` ให้มือถือหรือคอมเครื่องอื่นในวงแลนเปิด `http://<IP ของคอมนี้>:8080` ได้ด้วย ค่าเริ่มต้นเปิดได้เฉพาะเครื่องตัวเอง
- `--port 9000` เปลี่ยนพอร์ต
- `--site https://...` ส่งผลไปเว็บ Vercel อื่น (ค่าเริ่มต้นคือ https://object-detection-vehicle-license.vercel.app)
- `--any-host` ยอมให้เปิดกล้องที่อยู่นอกวงแลน ปกติตัวกลางเปิดได้เฉพาะ IP ในวงแลน (10.x, 172.16-31.x, 192.168.x, 169.254.x) เพื่อไม่ให้ถูกใช้เป็นพร็อกซีไปที่อื่น
